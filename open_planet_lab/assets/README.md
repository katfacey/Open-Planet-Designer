# Runtime asset bundle

This source repository retains provenance and LOD manifests. The large model libraries, elevation maps, textures and atlases are supplied in the complete beta add-on ZIP on the Releases page.

For development, run `python tools/restore_assets.py /path/to/Open-Planet-Designer-1.3.0-beta.1.zip` to copy its verified runtime asset members into this folder. The archive must be the release package, not GitHub's automatically generated source ZIP. Keep the provided source manifests and notices.
