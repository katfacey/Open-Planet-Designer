# Native runtime photographic reference board

Selected 1 November 2026. These are photographic references for the first woodland/meadow and later alpine benchmark. The native streaming alpha has **not** passed photographic review. Links are retained here; the reference images are not bundled in the application or represented as project renders.

| Reference | Source / rights | What to inspect |
| --- | --- | --- |
| [Forest Slope](https://polyhaven.com/a/forest_slope), Andreas Mischok | Poly Haven lists this captured HDRI as CC0 | Pine silhouette, irregular spacing, moss/rock/litter relationships, dappled morning light and shaded slope depth |
| [Meadow at Paradise](https://commons.wikimedia.org/wiki/File:Meadow_(dba8072c688346f48570dfe6a96ceea5).JPG), Kevin Bacher / NPS, 27 August 2006 | File record identifies an official NPS employee photograph and US public-domain status; original NPGallery accession retained in the URL | Plant height/coverage, meadow structure, real ground variation and mountain-to-foreground scale |
| [Mount Rainier from Spray Park](https://commons.wikimedia.org/wiki/File:Mount_Rainier_from_Spray_Park_(539e94e6-3b45-4491-bbab-e9b3959571a8).JPG), NPS, 10 August 2017 | File record identifies an official NPS photograph and US public-domain status; source is NPGallery | Meadow/forest edge, exposed rock, regional relief and atmospheric contrast over distance |

The first image is a lighting/environment reference, not a matched ground-level camera. The NPS scenes are subalpine references, not permission to mix their species indiscriminately into every woodland. Keep habitat and weather consistent when selecting final matched cameras. Before redistributing a downloaded reference, retain the original file, source/license metadata and checksum; gallery/promotional CG images are not interchangeable with the licensed source assets.

For the native benchmark, capture human-height, canopy-height and aerial views, plus front light, side/backlight and overcast cases. Compare plant form/coverage, physical scale, contacts, substrate, shadow depth and distant contrast separately. Keep high-detail stills separate from streaming/LOD motion tests. The current simple sky/ambient lighting, sparse benchmark ecology, ground repetition and distant tree cards remain visible gaps.

No metric or selected photograph establishes photographic approval by itself. Record the reviewed images, camera/light differences and a human visual decision when M4 is evaluated.
